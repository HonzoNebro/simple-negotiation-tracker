# Rules Inspiration

Simple Negotiation Tracker is inspired by the negotiation procedures in Draw Steel, especially the ideas of tracking an NPC's interest, patience, motivations, and conversational pitfalls.

Reference material:

- Steel Compendium, Chapter 11: Negotiation: https://steelcompendium.io/compendium/main/Rules/Chapters/Negotiation/
- Steel Compendium root: https://steelcompendium.io/compendium/main/
- Draw Steel Creator License: https://www.mcdmproductions.com/draw-steel-creator-license

This module is not a Draw Steel rules implementation. It does not automate negotiation tests, reproduce full rules text, include Draw Steel artwork, use the MCDM logo, or claim official status. It is a manual Foundry VTT tracker that can be used with any game system.
